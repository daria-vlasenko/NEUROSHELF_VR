## Этап 3. Финальная сборка

Development-сборки ЛР9 содержат профилировщик, поэтому добавлен пункт **NEUROSHELF → Сборка → Release Windows x64** (`Assets/Editor/NeuroshelfReleaseBuild.cs`): проверяет сцену в списке, переключает платформу, снимает Development / Autoconnect Profiler, вызывает `BuildPipeline.BuildPlayer`.

| Параметр | Значение |
|---|---|
| Платформа | Windows (Standalone) |
| Архитектура | x64 |
| Тип | Release (без Development Build и Profiler) |
| Сцены | 0: `Assets/_Project/Scenes/02_Store.unity` |
| Результат | Succeeded, ошибок 0 |
| Время сборки | 94 с |
| Размер | 227,0 МБ по BuildReport; NEUROSHELF_VR.exe — 652 КБ, UnityPlayer.dll — 35 МБ |
| Путь | `NEUROSHELF_VR/Builds/Release/NEUROSHELF_VR.exe` |

Папку `NEUROSHELF_VR_BurstDebugInformation_DoNotShip` при передаче сборки не копировать — это отладочные символы Burst.

## Ограничения

- шлема нет: всё проверено в редакторе и через XR Device Simulator, поза задаётся скриптом;
- читаемость — расчётом для шлема класса HTC Vive (≈10 px/°), без испытуемых;
- сборка десктопная (Windows x64 + OpenXR, PC VR), автономные Android-шлемы не рассматривались;
- дрожание холстов оценено визуально в симуляторе, без реального трекинга.
